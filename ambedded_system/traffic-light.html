Arduino Traffic Light

Three LED traffic light control using Arduino UNO. This project simulates a basic traffic signal using red, yellow and green LEDs.

Components

Arduino UNO Red LED Yellow LED Green LED 220Ω Resistors Jumper Wires

Wokwi Simulation

⚡ OPEN IN WOKWI

Arduino Code

traffic-light.ino 
int led13 = 13;
int led11 = 11;
int led9 = 9;

void setup() {

    pinMode(led13, OUTPUT);
    pinMode(led11, OUTPUT);
    pinMode(led9, OUTPUT);

}

void loop() {

    digitalWrite(led13, HIGH);
    delay(10000);

    digitalWrite(led13, LOW);
    delay(30);


    digitalWrite(led11, HIGH);
    delay(15000);

    digitalWrite(led11, LOW);
    delay(25);


    digitalWrite(led9, HIGH);
    delay(15000);

    digitalWrite(led9, LOW);
    delay(25);

}
