Arduino LED blink

An Arduino program that turns an LED ON and OFF repeatedly at a fixed time interval.

Components

Arduino UNO 220 Ω Resistor Green LED Jumper Wires

Tinkercad Simulation

Arduino Code

LED_blink.ino 

// C++ code
//
void setup()
{
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop()
{
  digitalWrite(LED_BUILTIN, HIGH);
  delay(500); // Wait for 1000 millisecond(s)
  digitalWrite(LED_BUILTIN, LOW);
  delay(500); // Wait for 1000 millisecond(s)
}
